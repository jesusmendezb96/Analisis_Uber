## ✅ REGLA PRINCIPAL: ¿Cuándo es LABURO?

**Un viaje es LABURO si involucra CUALQUIERA de estas direcciones de trabajo:**

### Direcciones de Trabajo Conocidas

1. **Oficina Principal:**
   - `Avenida Leandro N. Alem 815` (cualquier variación: Av., Avenida, etc.)

2. **Oficina/Cliente - Puerto Madero:**
   - `Juana Manso 1746` (o cualquier dirección en Juana Manso)
   - `Juana Manso Ciudad de Buenos Aires`

3. **Cliente Principal - Munro:**
   - `Alferez Hipólito Bouchard 4191`
   - `Alférez Hipólito Bouchard` (cualquier número en esta calle)
   - `Alferez Hipólito Bouchard, B1605BNA Munro`

4. **Otros Clientes:**
   - `Av. Dorrego 2520`
   - `Av Córdoba 111` (si aparece)
   - `Torre BBVA` (si aparece)

### ⚠️ REGLA CRÍTICA: Casa ↔ Cliente = LABURO

**TODOS estos casos son Laburo:**
- ✅ Casa → Cliente
- ✅ Cliente → Casa
- ✅ Casa → Oficina
- ✅ Oficina → Casa
- ✅ Cliente A → Cliente B
- ✅ Oficina → Cliente

**NO importa que el otro extremo sea tu casa. Si involucra una dirección de trabajo, es LABURO.**

## ❌ REGLA PERSONAL: ¿Cuándo es Personal?

Un viaje es **Personal** si:

1. **NO involucra ninguna dirección de trabajo** (de la lista de arriba)
2. **Y** al menos uno de estos:
   - Involucra tu casa (`Av. Juan Bautista Alberdi 1880`)
   - Es un viaje entre direcciones personales conocidas
   - Es fin de semana a lugares no laborales

### Direcciones Personales Conocidas

- **Tu casa:** `Av. Juan Bautista Alberdi 1880`
- **Salidas nocturnas:** `El Hornero 266`, `Av. Boedo`, `Salta 1054`, etc.
- **Fin de semana:** `Av. S. Martín 7216` (31/12, 1/1), `Avenida Carlos Calvo`, etc.

## 🚨 ERRORES COMUNES A EVITAR

### ❌ ERROR 1: Marcar Casa → Cliente como Personal
```
Casa → Alferez Hipólito Bouchard = ❌ INCORRECTO si lo marcas Personal
                                  = ✅ CORRECTO: Es LABURO
```
**Resultado:** Pierdes el reembolso de ese viaje.

### ❌ ERROR 2: No reconocer todas las direcciones de trabajo
```
Si "Juana Manso 1746" no está en tu lista → Lo marcas Personal
= PIERDES DINERO
```

### ❌ ERROR 3: Pensar que Casa = Personal
```
Casa → Oficina = LABURO (no Personal)
Oficina → Casa = LABURO (no Personal)
```

## 🔍 Cómo Categorizar Paso a Paso

### Paso 1: Lee origen y destino

### Paso 2: Pregunta: ¿Involucra ALGUNA dirección de trabajo?

Busca en origen O destino:
- ¿Contiene "Leandro N. Alem 815"?
- ¿Contiene "Juana Manso"?
- ¿Contiene "Alferez Hipólito Bouchard" o "Alférez Hipólito Bouchard"?
- ¿Contiene "Dorrego 2520"?

**Si SÍ** → ✅ **LABURO** (terminar aquí, no importa qué más)

**Si NO** → Continúa al Paso 3

### Paso 3: ¿Es fin de semana o feriado?

- Sábado/Domingo → Probablemente Personal
- 31/12, 1/1, feriados → Probablemente Personal

### Paso 4: ¿Es horario laboral? (opcional)

- Lunes-Viernes 9am-6pm → Revisar con más cuidado
- Noche/madrugada → Probablemente Personal

### Paso 5: ¿Reconoces la dirección como personal?

- `El Hornero 266` → Personal
- `Av. Boedo` → Personal
- `Salta 1054` → Personal
- Direcciones desconocidas → Revisar manualmente
